## 病原体（多病因）

突眼病不是单一病原，而是多种病因导致的共同症状，治疗前**必须先分清类型**：

| 病因类型 | 常见病原/原因 | 特点 |
|---|---|---|
| 细菌性 | 弧菌（*Vibrio* spp.）最常见，其他革兰氏阴性菌 | 最常见类型，单眼多发，眼周红肿 |
| 寄生虫性 | 复口吸虫（*Diplostomum*）幼虫钻入眼球 | 相对少见 |
| 营养/环境性 | 维生素缺乏、氨氮超标、物理损伤 | 双眼对称突出，无充血 |

### 为什么容易误诊

- 单眼突眼 ≠ 一定是细菌——物理损伤（撞缸、被咬）也会单眼肿胀
- 双眼对称突出 ≠ 一定是营养问题——氨氮急性超标同样可致双眼肿胀
- **先查水质、再观察行为，最后才考虑用药**，是突眼病诊疗的基本顺序

## 症状识别

- **眼球突出**：单眼或双眼明显突出于眼眶外，超出头部轮廓 1/3 以上
- **细菌性特征**：眼球外膜**白浊、充血**，眼周红肿；重症时眼球内充满白色不透明液体，眼球胀大如泡
- **营养/环境性特征**：**双眼对称突出**、无充血发炎——这是区别于细菌性的关键
- **行为变化**：游动迟缓、沉底、侧翻
- **终末期**：眼球破裂、脱落——不可逆损伤

### 观察要点

| 观察项 | 指向 |
|---|---|
| 单眼突出 + 眼周红肿 | 细菌性或物理损伤 |
| 双眼对称突出 + 无充血 | 水质/营养问题 |
| 伴随拖便、白便 | 注意是否与肠炎（07 篇）同源 |
| 伴随立鳞、腹水 | 全身性感染，预后较差 |

## 治疗

### 第一步：查水质（所有病例的第一步）

检查三项核心指标：

| 指标 | 安全范围 |
|---|---|
| 氨氮 | &lt;0.2ppm |
| 亚硝酸盐 | &lt;0.1ppm |
| pH | 6.5-7.8 |

**水质问题优先处理**：换水 30% + 盐浴 0.1-0.3% + 升温至 28-30℃ + 停食 3 天。多数环境性突眼在改善水质后即可缓解。

### 第二步：按病因用药

| 病因 | 治疗方案 | 说明 |
|---|---|---|
| 细菌性 | 广谱抗菌药药浴：黄粉/呋喃西林按说明书；氟哌酸 5mg/L 药浴 5-7 天；土霉素按说明 | 治疗期间**停用活性炭**（吸附药物）；治疗缸独立操作 |
| 寄生虫性 | 敌百虫 0.2ppm 药浴（需谨慎），或吡喹酮口服 | 敌百虫剧毒，精确计量，无鳞鱼禁用 |
| 营养性 | 维生素拌料投喂（多维片碾碎拌饲料） | 配合改善投喂结构 |

### 治疗期护理

- 独立治疗缸，爆氧、遮光、静养
- 每日少量等温换水配合补药
- 症状缓解后继续用药 1-2 天防复发
- 眼球损伤不可逆的部分（白浊、浑浊）无法恢复如初，但控制感染可保住视力与生命

## 预防

- **水质监控**：定期检测氨氮、亚硝酸盐、pH，每周换水 1/3
- **合理投喂**：控制喂食量，饲料多样化，避免单一饲料导致营养失衡
- **维生素均衡**：定期补充维生素（拌料或选用营养全面的饲料）
- **避免损伤**：操作轻柔、混养温和，防止物理性眼部损伤

### 治疗缸设置（标准配置）

| 项目 | 配置 |
|---|---|
| 缸体 | 小型裸缸 5-20L，无底砂、无装饰、无水草 |
| 过滤 | 海绵过滤或水妖精；药浴期间可暂停过滤，靠爆氧维持溶氧 |
| 加热棒 | 设定 28-30℃（细菌性感染治疗温度） |
| 水源 | 用原缸水或等温困水 |
| 换水 | 每天换水 1/3 等温，配合补药 |

### 观察时间线（供参考）

| 时间 | 预期表现 |
|---|---|
| 治疗第 1-3 天 | 突眼不再加重，眼周红肿消退（细菌性） |
| 治疗第 4-7 天 | 眼球肿胀减轻，游动恢复 |
| 治疗第 1-2 周 | 眼球明显回位，白浊逐步减轻 |
| 终末期 | 白浊/浑浊可能留下永久痕迹，但感染已控制 |

### 常见问题

**突眼一定要用药吗？** 不一定。先查水质——氨氮、亚硝酸盐超标引起的突眼，换水 + 盐浴 + 升温 + 停食后多能自行缓解。只有水质正常仍无改善时，才考虑细菌性感染用药。

**单眼突眼和双眼突眼用药一样吗？** 不一样。单眼突出伴红肿多为细菌性或物理损伤，用抗菌药；双眼对称突出无充血多为水质/营养问题，先改善水质、补充维生素，不要盲目上抗菌药。

**眼球里的白浊能恢复吗？** 细菌感染导致的眼内浑浊属于组织损伤，即使感染控制，也可能留下永久性白斑或视力受损。治疗目标是保命、控感染，恢复程度因个体而异。

**突眼会传染其他鱼吗？** 细菌性突眼有传染风险，应立即隔离；水质性问题则全缸同步改善水质即可。

### 用药总则提醒

- ① 一切以药品说明书为准
- ② 优先市售观赏鱼专用药
- ③ 治疗缸操作，勿在原缸下药（破坏硝化系统）
- ④ 不同药物不混用
- ⑤ 治疗期停用活性炭
- ⑥ 避光药物注意遮光
- ⑦ 无鳞鱼、幼鱼、虾螺敏感，剂量减半

> 突眼病分型不清时，宁可用温和方案（换水 + 盐浴 + 升温）观察 48 小时，也不要盲目叠加抗菌药——用错方向会延误真正的病因。
