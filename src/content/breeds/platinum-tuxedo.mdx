## 品种简介

白金礼服（Platinum Tuxedo）是<strong>白金系 × 礼服系</strong>的结合品种，也是白金系中最具代表性的品种之一。白金系的核心理念是<strong>鱼体覆盖均匀的白金反光鳞片</strong>，强调金色、银白、白金色调的统一与覆盖度；而礼服系则在后半身（腰身至尾柄）呈现黑色或深蓝色的纯色调"礼服斑"，尾鳍单一纯色、不掺杂斑点。两者叠加，便构成了白金礼服：前半身银白反光、后半身深色礼服斑，对比鲜明。

白金礼服属于白金系，白金系在传统 17 大品系中以其反光鳞片覆盖度为品鉴核心。礼服系本身起源悠久，德系黄尾礼服 1960 年代诞生于德国法兰克福（Gerhard Gellrich 培育），此后衍生出白尾礼服、出租车黄等众多分支；白金礼服则是这一经典结构在白色反光表现上的延伸。

品鉴白金礼服有一条"白金标准"：反光鳞片要求<strong>覆盖均匀</strong>，理想的个体最好连各鳍均覆盖白金反光——背鳍、尾鳍乃至臀鳍都泛着同样的白金光泽，才称得上完整。覆盖不均、局部发灰发暗，都会显著拉低品相。

## 特征与鉴别

- <strong>体色</strong>：鱼体覆盖均匀的白金反光鳞片，以金色、银白、白金色调为主；理想个体连各鳍均覆盖白金反光
- <strong>礼服斑</strong>：后半身（腰身至尾柄）为黑色或深蓝色纯色调斑块，与前半身白金反光形成强烈对比
- <strong>尾鳍</strong>：单一纯色、不掺杂斑点，标准三角尾（Delta）表现
- <strong>背鳍</strong>：礼服系背鳍通常宽大，白金礼服在此基础上追求背鳍同样覆盖白金反光
- <strong>体型</strong>：与礼服系一致，一般 3～5 厘米，部分资料称成年个体可达 6 厘米

### 变异型一览

| 变异型 | 说明 |
|---|---|
| 黄白金 | 马特利（Martelly）表现，白金基调偏金黄 |
| 红白金 | 珊瑚红表现，白金基调偏珊瑚红 |
| 蓝白金 | 珊瑚蓝表现，白金基调偏珊瑚蓝 |
| 绿白金 | 白金基调偏绿光 |

### 品鉴要点

1. <strong>反光覆盖度</strong>：白金鳞片覆盖面积越大、越均匀，品相越高
2. <strong>鳍部覆盖</strong>：各鳍是否同样反光，是区分精品与普通个体的关键
3. <strong>礼服斑纯度</strong>：深色斑块须纯正、边界清晰，不得混入杂色
4. <strong>尾鳍展开</strong>：三角尾夹角度越大越好，展开自然者为上

### 鉴别要点

- 与白金草尾的区别：草尾尾鳍布满细小喷点，白金礼服尾鳍为纯色
- 与白金马赛克的区别：马赛克尾鳍纹路粗大且有蓝色块，礼服斑为纯色块
- 与普通银白色孔雀鱼的区别：礼服斑的存在是"礼服"命名的核心依据

## 饲养要点

| 项目 | 建议 |
|---|---|
| 水温 | 22-28℃，稳定在 24-26℃ 为宜 |
| 水质 | 中性至弱碱性（pH 7.0-7.8） |
| 光照 | 白光 LED 下白金反光效果最佳 |
| 缸体 | 每对成鱼建议 20 升以上水体 |
| 过滤 | 缓流水流，避免强过滤冲击鱼鳍 |
| 换水 | 每周换水 1/4～1/3，保持水质稳定 |
| 难度 | 中等，反光表现对水质敏感 |
| 混养 | 性格温和，可与同体型孔雀鱼混养 |

白金反光鳞片的表现与水质、光照关系密切。水质波动时反光会变暗、发灰，恢复稳定后通常能逐渐找回光泽，因此<strong>规律换水、保持水质稳定</strong>是维持品相的关键。饲料方面可搭配增色饲料与植物性饲料，避免过度喂食导致体型走样。

日常维护上，白金礼服不挑食、适应力尚可，但换水时注意温差不要超过 1-2℃，加水缓慢避免冲击鱼体。观赏时白光 LED 最能呈现反光质感，黄光下白金效果会打折扣。

## 繁殖与提纯

礼服斑遵循伴 X 显性遗传（X(T)X(T)、XX(T)、X(T)Y），因此<strong>母鱼也能表现礼服斑</strong>，提纯路径比纯 Y 连锁品系更宽。选种要点：

- 种公鱼：优先选择白金反光覆盖度最高、连鳍部都反光、礼服斑边界清晰的个体
- 种母鱼：选择体格健壮、礼服斑规整的个体，母鱼体色背景直接影响子代白金色调
- 提纯方向：固定白金反光覆盖度 + 礼服斑的纯度，避免引入草尾、马赛克等纹路基因
- 淘汰策略：白金覆盖不足、出现杂色斑点、礼服斑不规整的个体一律淘汰

实际操作可参考以下流程：

1. 选取一对品相稳定的种鱼单独入缸（雌鱼临产时放入隔离盒待产）
2. 子代满月后按"反光覆盖度 → 礼服斑纯度 → 尾鳍展开"的顺序初筛
3. 达标个体进入第二缸继续培育，未达标个体转作观赏或淘汰
4. 下一代回交表现最稳定的亲本，巩固白金覆盖度
5. 连续三至四代筛选，品系特征即可基本稳定

## 备注

白金礼服的饲养难度为中等——并不是难养，而是<strong>品相维持有门槛</strong>：白金反光对水质和光照敏感，礼服斑对纯度要求高。市售普通个体的适应力尚可，但从零开始提纯一缸稳定表现的白金礼服，需要耐心与多代筛选。

一个常见的误区是"反光越亮越好"——实际上白金系的品鉴标准是<strong>覆盖均匀</strong>，局部过亮而其他部位发灰反而不如整体均匀的个体。新手若想尝试，可从品相稳定的成鱼入手，边养边学，再逐步进阶到自繁自筛。
