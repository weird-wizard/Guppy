## 品种简介

珊瑚双剑（Coral Double Sword）是珊瑚系的代表品种，以<strong>身体侧线附近的长条形红色色块</strong>（珊瑚红特征）搭配双剑尾而闻名。珊瑚系在品系归属上属于<strong>白金总系</strong>——珊瑚红正是白金系红色变异（红白金）的表现：在白金反光基调上发展出的珊瑚红色调。

双剑尾属于剑尾系（Sword Tail），尾鳍上下缘各伸出一根如剑般笔直、末端尖锐的延长鳍条。剑尾是<strong>尾型分类，可叠加任何品系</strong>，珊瑚双剑正是"珊瑚红体色 + 双剑尾型"的组合。在 WGA 的尾型分组中，双剑与上剑、下剑、琴尾同属<strong>剑尾组</strong>，是所有尾型中辨识度最高的一类。

珊瑚双剑体型一般较大，在同品系中属于气场较强的一类。与常见的三角尾品种相比，双剑尾的流线造型让整条鱼显得更加修长凌厉，游动时两柄"剑"随水流摆动，观赏性极强，是进阶鱼友偏爱的品种之一。

## 特征与鉴别

- <strong>珊瑚红特征</strong>：身体侧线附近分布长条形的红色色块，这是珊瑚系最具辨识度的标志
- <strong>双剑尾</strong>：尾鳍上下各伸出一根笔直尖锐的剑状鳍条，末端无分叉
- <strong>体型</strong>：体型一般较大，成年雄鱼视觉上比多数三角尾品种更显修长健壮
- <strong>底色</strong>：在白金总系框架下，红色色块与白金反光底色相互衬托
- <strong>游姿</strong>：双剑延长鳍条随水流自然摆动，游动姿态舒展

### 品鉴要点

1. <strong>剑条笔直度</strong>：上下两剑笔直、对称，弯曲或歪斜为重大瑕疵
2. <strong>剑条长度</strong>：剑条延伸越长越醒目，但须与整体比例协调
3. <strong>色块完整性</strong>：侧线红色色块长条形完整、边界清晰，不破碎
4. <strong>红色饱和度</strong>：在白金总系框架下，红色越鲜艳、与底色反差越大越好

### 鉴别要点

- 与白金双剑的区别：白金双剑以白金反光为主，珊瑚双剑以侧线珊瑚红色块为主
- 与日本蓝双剑的区别：日本蓝双剑核心是尾柄处的亮蓝色反光色块，珊瑚双剑是红色色块
- 与金属蛇王剑尾的区别：后者以蛇纹与金属色为核心，珊瑚双剑无蛇纹

## 饲养要点

| 项目 | 建议 |
|---|---|
| 水温 | 22-28℃，稳定在 24-26℃ 为宜 |
| 水质 | 中性至弱碱性（pH 7.0-7.8），忌剧烈波动 |
| 光照 | 白光下红色色块与白金底色层次分明 |
| 缸体 | 建议宽敞缸体，保证双剑有足够活动空间 |
| 过滤 | 缓流为主，避免剑条被水流长时间冲压变形 |
| 喂食 | 搭配增色饲料可加深珊瑚红表现 |
| 难度 | 进阶（advanced），品相维持与尾型完整度要求高 |
| 混养 | 与性情温和的品种混养，避免追逐伤及剑尾 |

双剑尾的延长鳍条是<strong>最脆弱的部分</strong>：捞鱼时用宽口网、换水时避免强水流冲击、缸内避免尖锐造景石，都是保护剑尾的基本功课。珊瑚红的饱和度与白金总系的反光表现同样对水质敏感，水质稳定时色块更鲜艳、反光更亮。

日常维护中还应留意：双剑尾一旦断裂不会完全恢复原样，因此日常操作务必轻柔；混养对象建议选择无咬鳍习惯的温和品种，尽量避免与燕尾、缎带等延伸鳍品种混养，减少互相追逐造成的损伤。

## 繁殖与提纯

- 双剑尾为独立尾型性状，可与其他品系叠加，因此<strong>先固定尾型、再固定体色</strong>是常见路线
- 种公鱼：选择双剑笔直、对称、长度达标，且侧线珊瑚红色块清晰完整的个体
- 种母鱼：选择体格健壮、体型较大的个体，母鱼体型对子代"体型较大"的特征贡献明显
- 提纯方向：珊瑚红色块的面积与纯度是核心，避免混入草尾、蛇纹等纹路基因干扰
- 淘汰策略：剑尾弯曲、分叉、色块模糊或出现杂色的个体一律淘汰

操作流程建议如下：

1. 种公鱼单独确认双剑对称、无分叉后，与体型健壮的种母鱼合缸
2. 母鱼临产前移入隔离盒待产，避免剑尾在追逐中被咬伤
3. 子代长至 2 个月左右剑尾成型，先筛剑条笔直度，再筛色块表现
4. 达标个体与原缸稳定亲本回交一代，巩固尾型遗传
5. 连续多代筛选，同时淘汰体色混杂个体，双剑与珊瑚红即可同步稳定

## 备注

珊瑚双剑被列为进阶（advanced）品种，难度并不在于饲养本身，而在于<strong>尾型与体色的双重提纯</strong>：双剑尾需要多代筛选才能稳定，珊瑚红色块又对血统纯度敏感。作为白金总系的一员，它的红色表现与白金反光的平衡也是品鉴的看点。

值得注意的是，剑尾类品种的繁殖量通常需要比三角尾品种更大，因为剑条的对称性、笔直度在子代中的符合率并不高。对追求"大、红、剑"效果的进阶鱼友来说，珊瑚双剑是很有收藏价值的一尾，也常被用来与其他品系杂交、培育新的剑尾变体。
