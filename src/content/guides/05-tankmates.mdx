孔雀鱼性格温和，几乎可以和所有同体型、同水质的温和鱼混养——但"几乎"二字背后有不少坑：有的鱼会啃孔雀鱼的招牌大尾巴，有的鱼水温要求完全不同，还有的鱼会把它当点心。混养前先读本文，避免"买回来才知道是凶手"的惨剧。

混养的意义不只是"热闹"：合理的鱼种搭配还能各司其职——鼠鱼清残饵、黑壳虾除藻、上层中层底层分层活动减少冲突。选对室友，鱼缸是一个和谐的小社会；选错室友，一夜之间就可能"惨案"收场。

## 一、混养四大原则

四条原则不是并列的建议，而是**必须同时满足的准入门槛**——缺任何一条，混养就埋下了隐患。

1. **水质兼容**：选择同样喜欢弱碱性水的鱼（孔雀鱼适宜 pH 6.8-8.5、最佳 7.0-7.8），避免"一个要酸、一个要碱"的组合——硬凑的结果是某一方长期处于亚健康
2. **体型相近**：体型差距控制在 **≤2cm** 以内——差距过大，小的会被当成食物，大的会被当成威胁
3. **性格温和**：避开有咬鳍习性的鱼——孔雀鱼的大尾巴在攻击性鱼眼里就是"靶子"
4. **水层互补**：不同水层的鱼各占一层，减少领地冲突，也让缸里更热闹（上层孔雀鱼、中层灯鱼、底层鼠鱼是经典搭配）

## 二、推荐混养对象

### 推荐混养表

| 鱼类 | 特点 | 混养注意 |
|---|---|---|
| 灯科鱼（红绿灯/宝莲灯/红鼻剪刀） | 群游漂亮、性格温和 | 注意灯科鱼偏好中性水，微碱偏酸缸需谨慎 |
| 月光鱼/米奇鱼 | 同为胎生鳉科，习性最接近 | 几乎零风险，繁殖思路也相同 |
| 玛丽鱼 | 温和、中上层活动 | 食量不小，注意别抢食过度 |
| 鼠鱼 | 底层活动、清理残饵 | 天然"清道夫"，缸底卫生帮手 |
| 斑马鱼 | 皮实、游速快 | 抢食凶猛，注意喂食时照顾孔雀鱼 |
| 黑壳虾/极火虾 | 除藻、清残饵 | 会被成鱼捕食幼虾，需密植水草提供庇护 |
| 小精灵鱼 | 温和的食藻鱼 | 需要稳定藻源，草缸混养优选 |

### 60 升缸混养实例

一个经典且稳妥的配置：**5 条孔雀鱼 + 10 条灯鱼 + 3 条鼠鱼**。上层孔雀鱼群游、中层灯鱼成群闪烁、底层鼠鱼埋头清残饵，三层各司其职，观赏性和水质管理双赢。

组合分析：

- **5 条孔雀鱼**：最好 1 公 4 母或全母，避免多公互斗追尾；占据上层水面区域
- **10 条灯鱼**：群游效果需要数量撑起来，10 条是起步数；占据中层
- **3 条鼠鱼**：底层清理残饵，是缸底的"保洁员"；注意鼠鱼需要细砂底，避免尖锐砂石划伤触须
- 总密度（18 条鱼 / 60 升）远低于 2 条/升上限，水质压力小，新手也能驾驭

> 💡 进阶玩法：在上述基础上加黑壳虾或极火虾除藻、加小精灵鱼啃缸壁，只要遵守四条原则，缸越大越从容。

## 三、不能混养的对象

| 鱼类 | 为什么不能混 |
|---|---|
| 虎皮鱼 | **最著名的禁忌**——啃鳍是天性，孔雀鱼的丝状大尾鳍正是它的目标，几天就能啃成"扫帚" |
| 斗鱼（泰国斗鱼） | 领地意识极强，会把孔雀鱼当入侵者攻击 |
| 金鱼/锦鲤 | 水温冲突（金鱼喜冷水，孔雀鱼需 22-28℃）+ 体型差距大，直接吞食 |
| 大型慈鲷/地图鱼 | 掠食性鱼类，孔雀鱼就是活饲料 |
| 大型清道夫（成年） | 夜间会吸食鱼体表黏液，孔雀鱼体表娇嫩，极易受伤感染 |
| 曼龙鱼/红十字鱼 | 咬鳍习性，与虎皮鱼同类问题 |

> ⚠️ 判断标准永远看三条：**会不会咬鳍、水温水质是否兼容、体型会不会构成捕食关系**。满足不了任何一条，再好看也别混。

### 黑名单背后的逻辑

- **咬鳍类**（虎皮鱼、曼龙鱼、红十字鱼）：这是刻在基因里的行为，不是"养熟了就会改"——被啃残的尾鳍很难完全恢复，且伤口易感染
- **攻击/捕食类**（斗鱼、慈鲷、地图鱼、金鱼/锦鲤）：要么领地意识强，要么体型碾压，孔雀鱼在它们面前没有任何自保手段
- **慢性伤害类**（大型清道夫成年体）：白天相安无事，晚上偷偷吸鱼，第二天鱼体表出现白色擦伤才被发现，为时已晚

## 四、混养注意事项

1. **幼鱼 &lt;2cm 不要混养**：这个体型的孔雀鱼苗混入混养缸几乎等于送死——安全合缸尺寸是 **2-2.5cm 以上**
2. **混养前检疫 7-10 天**：新鱼先隔离观察，确认无病、无寄生虫再合缸，防止交叉感染毁掉整缸鱼
3. **重新计算密度**：混养后鱼口增加，按"约 2 条/升"的上限重新核算总数量，必要时降低各品种数量
4. **先观察再定夺**：合缸后前 3 天重点观察是否有追咬、抢食不均，发现问题及时隔离调整

### 检疫流程怎么做

- 准备一个检疫缸（可用小缸或大号整理箱，配简单过滤和加热）
- 新鱼入检疫缸前同样走**过温过水**流程（漂浮 15-30 分钟适应温差，分次加水适应水质）
- 检疫期内正常少量喂食、勤观察体表与粪便，出现白点、缩鳍、烂尾等症状先治疗再合缸
- 7-10 天无异常后，再合入主缸——这 7-10 天的耐心，能避免整缸鱼团灭的代价

## 五、加鱼顺序与合缸时机

混养不是"一次性把鱼全买回来倒进去"，顺序和时机同样重要：

1. **先铺好环境再进鱼**：水草密植到位、过滤运转、养水完成（详见《新手入门》养水流程），再开始加鱼
2. **主鱼先入缸**：先放孔雀鱼，让它在自己的"主场"建立安全感；后入的鱼天然处于"新来的"弱势，冲突更少
3. **批次少量加**：一次只加 1-2 个品种、每品种少量，隔 1-2 周再补下一批，给硝化系统逐步适应鱼口增长的时间
4. **弱势鱼最后加**：鼠鱼、虾等底层生物放在最后，此时缸内环境成熟、水草丰茂，它们有足够的庇护
5. **合缸当晚留灯观察**：合缸后当晚多观察半小时，追咬行为通常在前几小时就会暴露，及时介入成本最低

> ⚠️ 加鱼不是"购物爽感"，是给鱼缸做"负载测试"——每批新鱼都是对硝化系统的一次压力测试，分批加鱼 = 分批测试，出问题也知道出在哪一批。

## 六、常见混养问题

| 问题 | 判断 | 处理 |
|---|---|---|
| 新鱼入缸后总被追 | 领地冲突或体型差异过大 | 先隔离观察，检查是否满足四条原则 |
| 孔雀鱼尾鳍莫名破损 | 水质差或混养被咬 | 测水质；观察攻击者，必要时隔离 |
| 抢食时孔雀鱼吃不到 | 混养了游速快/抢食猛的鱼（如斑马鱼） | 分散投喂点，或先喂孔雀鱼再喂抢食鱼 |
| 鱼缸里虾越来越少 | 虾被当成零食了 | 密植水草给虾提供庇护，或接受"虾是消耗品" |
| 混养后水变浑浊 | 密度超载、过滤不足 | 减密度或加强过滤，重新核算容量 |

## 七、混养前自检清单

动手买鱼之前，把这份清单过一遍，每项都打勾再出手：

- [ ] **水质对齐**：新鱼的 pH/硬度偏好与孔雀鱼一致（孔雀鱼适宜 pH 6.8-8.5、最佳 7.0-7.8），不是"大概差不多"
- [ ] **体型检查**：成体尺寸与孔雀鱼差距 ≤2cm——查的是成体尺寸，不是买回来时的大小
- [ ] **性格确认**：该品种没有咬鳍、领地攻击的习性记录，别赌个体差异
- [ ] **水层规划**：缸里已经有几个水层了？新鱼填的是空层还是挤进别人的领地
- [ ] **密度核算**：按约 2 条/升重新算过总数，混养后不超过上限
- [ ] **检疫安排**：检疫缸准备好了，能坚持隔离 7-10 天再合缸
- [ ] **应急预案**：如果出问题（追咬、抢食、带病），有没有地方隔离、有没有把握处理

> ⚠️ 清单里任何一项答不上来，就先别买。混养失败的代价不是一条鱼，而是整缸鱼的状态和信任。

### 给新手的进阶路线

- **第一缸（推荐）**：单养孔雀鱼，先把水质和密度玩明白
- **第二缸（进阶）**：按 60 升缸实例加灯鱼和鼠鱼，体验三层结构的和谐
- **第三缸（老手）**：加黑壳虾/极火虾、小精灵鱼，尝试草缸混养——此时你已经能读懂鱼的状态，出了乱子也兜得住

## 八、混养问答

**Q1：两条孔雀鱼公鱼会打架吗？**
会追尾但不致命——多公鱼环境下，弱势公鱼常被追得缩鳍、尾鳍开叉。想控数量就养"1 公多母"，想观赏群游就多备水草让弱势鱼有地方躲。

**Q2：混养缸能繁殖孔雀鱼吗？**
能，但幼鱼成活率低——成年鱼（包括孔雀鱼自己）都会吃幼鱼。想要小鱼，要么把临产母鱼捞到繁殖缸，要么在混养缸密植水草、莫丝当"天然保育所"。

**Q3：虾能和孔雀鱼混养吗？**
黑壳虾/极火虾可以，但幼虾会被当零食，靠密植水草保种群；注意**不能混大眼贼虾**等带钳的虾类，它们会反过来捕食小鱼。

**Q4：为什么我的灯鱼总是躲在水草里不出来？**
新入缸的灯鱼前 1-2 周躲藏是正常应激；若长期躲藏，检查是否混入了体型过大的鱼、灯光是否过强——安全感不足时它们会一直躲。

**Q5：混养缸水浑、氨氮高怎么办？**
先查密度：鱼口是否超过 2 条/升；再查投喂：残饵是不是超标。混养缸鱼口多，喂食总量大，换水频率应比单养缸更勤。

**Q6：混养缸要不要加盖？**
要。混养缸鱼多、活动频繁，受惊时跳缸概率更高——加盖是所有混养缸的标配，别等跳了鱼再后悔。

**Q7：新买的鱼太小，能和孔雀鱼合缸吗？**
看体长：小于 2cm 一律不合缸；2-2.5cm 是安全合缸尺寸的下限。合缸前先检疫 7-10 天，检疫期正好让小鱼再长一长。

**Q8：混养缸还需要繁殖缸吗？**
看目标。只观赏就无所谓；想稳定繁殖就必须备繁殖缸——混养缸里的鱼苗成活率极低，亲鱼自己都会吃苗。

## 九、混养速查

- **四原则**：水质兼容、体型差 ≤2cm、性格温和、水层互补
- **首选室友**：月光鱼/米奇鱼、玛丽鱼、灯科鱼、鼠鱼、小精灵鱼
- **进阶选择**：黑壳虾/极火虾（需水草庇护）、斑马鱼（注意抢食）
- **60 升缸参考**：5 孔雀鱼 + 10 灯鱼 + 3 鼠鱼
- **黑名单**：虎皮鱼、斗鱼、金鱼/锦鲤、大型慈鲷/地图鱼、大型清道夫、曼龙鱼/红十字鱼
- **红线**：幼鱼 &lt;2cm 不合缸；新鱼检疫 7-10 天；密度重新核算

> 一句话总结：**四条原则缺一不可，检疫 7-10 天雷打不动**——做到这两点，混养就是加法；做不到，混养就是减法。

混养得当，鱼缸就是一个和谐的小社会；混养失当，一夜之间就可能"惨案"收场——动手之前，先对照上面的原则。
