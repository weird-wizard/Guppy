## 一、水温

| 指标 | 数值 | 说明 |
|---|---|---|
| 适宜温度 | **22-28℃** | 多数来源共识 |
| 最佳温度 | **24-26℃** | 中国来源共识（也有称 22-24℃，不同来源说法不一） |
| 繁殖温度 | 25-28℃ | 繁殖期适当升温 |
| 耐受下限 | 18℃ 以下活动力/食欲下降 | 低于此易生病 |
| 致死温度 | 低于 10-13℃ 或高于 36℃ | 不同来源说法不一 |

**核心原则：温度稳定性比精确数值更重要。**

- 24 小时内温度波动不应超过 2℃
- 换水温差控制在 2℃ 以内（最好 1℃）
- 冬季必须使用加热棒恒温——这是孔雀鱼冬季大量死亡的头号原因
- 夏季水温超过 30℃ 时：代谢加快、溶氧降低、老母鱼易因钙流失脊椎弯曲，需降温（风扇降温/常换水/通风处放置）

## 二、pH 值（酸碱度）

| 指标 | 数值 |
|---|---|
| 适宜范围 | **pH 6.8-8.5**（弱碱偏中性） |
| 最佳范围 | **pH 7.0-7.8** |
| 中国地方标准 | pH 7.0-7.8（DB11/T 1511-2018） |

孔雀鱼偏好中性至弱碱性水，不喜欢酸性水。

**同样：稳定性 > 精确值。** pH 在合适范围内小幅波动远比追求某个精确数值重要；24 小时内 pH 大幅跳动比偏低更危险。

调节方式：
- 弱碱性滤材（珊瑚骨/珊瑚砂）可提升 pH 和硬度
- 沉木、榄仁叶可温和降酸
- **不建议用化学"pH 调节剂"猛调**——易反弹造成更大波动

> ⚠️ 换水少的老缸水会逐渐变酸，此时突然大量换新水会对鱼造成冲击。规律换水本身就是最好的 pH 维护。

## 三、硬度（GH/KH）

| 指标 | 数值 |
|---|---|
| GH（总硬度） | **8-15 dGH** 主流（部分来源给 8-25 宽幅） |
| KH（碳酸盐硬度） | 4-8 dKH |
| 繁殖 | 约 8 度硬度即可正常繁殖 |

- 孔雀鱼喜欢**偏硬、弱碱性**水
- 但其硬度适应能力极强——德国硬水和日本软水都能养好
- **不必过度追求调整硬度**；若自来水过软过酸，可在滤材中加珊瑚骨缓慢提升

## 四、氨氮、亚硝酸盐、硝酸盐控制

这是新手最易忽视的"隐形杀手"。氮循环：

> 鱼的排泄物和残饵 → **氨**（剧毒）→ **亚硝酸盐**（强毒）→ **硝酸盐**（低毒）

| 指标 | 饲养目标 | 危险阈值 |
|---|---|---|
| 氨氮（NH₃/NH₄⁺） | **接近 0 mg/L** | 0.25-0.5 mg/L 以上需立即处理 |
| 亚硝酸盐（NO₂⁻） | **接近 0 mg/L**（&lt;0.1） | 0.1 mg/L 以上即危险区 |
| 硝酸盐（NO₃⁻） | **&lt;20-40 mg/L** | 40 mg/L 以上需加强换水 |

补充知识：中国农业科学期刊 2019 年研究测定，孔雀鱼对氨氮、非离子氨、亚硝氮的 96 小时安全浓度分别为 12.54、0.55、1.77 mg/L——这是急性毒性试验的"致死安全浓度"，**实际饲养管理目标应远低于此**，接近 0 才是正确方向。

孔雀鱼对亚硝酸盐的耐受性远高于多数热带鱼（约为七彩神仙的 100 倍），但长期高浓度亚硝酸盐会伤害鳃部、降低免疫力。

**控制手段：**
1. 建立完整硝化系统（见新手入门篇）
2. 避免过量喂食（残饵是氨的主要来源）
3. 控制饲养密度
4. 定期换水稀释硝酸盐（**换水是去除硝酸盐的唯一有效手段**）
5. 水草可吸收部分硝酸盐

## 五、换水频率与方法

### 频率与水量

| 场景 | 建议 |
|---|---|
| 常规 | **每周 1 次，每次换 1/4-1/3** |
| 小型高密度缸 | 每周 2-3 次，每次 20-30% |
| 冬季低温 | 可延长至 10 天-半月 1 次 |
| 国际保守观点 | 每 2-4 周换 10-25%（不同来源说法不一） |

> 可按"水质测试结果 + 鱼的状态"灵活调整：硝酸盐偏高、鱼状态差 → 增加换水；水质稳定、状态好 → 维持常规。

### 换水正确步骤

1. 新水提前晾晒曝气 1-3 天除氯，或使用水质稳定剂
2. 新水与缸水**温差控制在 2℃ 以内**（最好 1℃）
3. 用虹吸管抽水，顺便吸除缸底粪便和残饵
4. 新水沿缸壁缓慢加入，或滴流加入，避免水流冲击鱼体
5. **不要在换水同时清洗过滤棉**（会导致硝化系统崩溃）

### 换水常见错误

- 直接用未除氯自来水 → 氯中毒
- 一次换水超过 50% → 水质震荡、鱼休克缩鳍
- 换水过于频繁（每天大量换） → 破坏硝化系统
- 新水温差过大 → 应激

## 六、水质速查表

| 参数 | 适宜范围 | 最佳值 | 备注 |
|---|---|---|---|
| 水温 | 22-28℃ | 24-26℃ | 波动 &lt;2℃/24h；繁殖 25-28℃ |
| pH | 6.8-8.5 | 7.0-7.8 | 弱碱性；稳定性 > 精确值 |
| GH | 8-15 dGH | 10-15 | 硬水更佳 |
| KH | 4-8 dKH | — | 过低则 pH 不稳 |
| 氨氮 | 0 mg/L | 0 | >0.25 需处理 |
| 亚硝酸盐 | 0 mg/L | 0 | >0.1 危险 |
| 硝酸盐 | &lt;20-40 mg/L | 越低越好 | 靠换水稀释 |
| 换水 | 每周 1 次 | 每次 1/4-1/3 | 温差 &lt;2℃ |
| 溶氧 | ≥5 mg/L | — | DB11 标准 |

把这几项指标打理稳定，孔雀鱼自然会回报你健康的状态和旺盛的繁殖力。
